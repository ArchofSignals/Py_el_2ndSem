Mathematical \& Physics FormulationTo transition from pure SNR inputs to real-world factors, we implement a linear link budget in decibels:$$\\text{Received SNR (dB)} = P\_{\\text{tx}} + G\_{\\text{tx}} + G\_{\\text{rx}} - PL(d) - X\_{\\sigma} - \\text{Noise Power (dBm)}$$Where:$P\_{\\text{tx}}$: Transmitter power (dBm)$G\_{\\text{tx}}, G\_{\\text{rx}}$: Antenna gains (dBi)$PL(d)$: Path loss over distance $d$ (dB)$X\_{\\sigma}$: Log-normal shadowing term (normal distribution $\\mathcal{N}(0, \\sigma^2)$ representing slow fading)A. Path Loss ModelsFree-Space Path Loss (FSPL):$$PL\_{\\text{FS}}(dB) = 20\\log\_{10}(d) + 20\\log\_{10}(f) - 147.55$$(where $d$ is distance in meters, $f$ is frequency in Hz)Log-Distance Path Loss Model:$$PL(d) = PL(d\_0) + 10 \\cdot n \\cdot \\log\_{10}\\left(\\frac{d}{d\_0}\\right) + X\_{\\sigma}$$(where $n$ is the path loss exponent depending on environment: $n \\approx 2$ for free space, $n \\approx 3$ to $5$ for urban environments)B. Small-Scale Fading DistributionsFading simulates destructive and constructive interference at the receiver over micro-distances or times:Rayleigh Fading (NLOS - No Line-of-Sight):Used for dense urban environments where the signal bounces off buildings with no direct path. The channel coefficient envelope $r$ follows a Rayleigh distribution:$$p(r) = \\frac{r}{\\sigma^2} e^{-\\frac{r^2}{2\\sigma^2}}, \\quad r \\ge 0$$Implementation: Modeled using complex Gaussian variables: $h = \\mathcal{N}(0, \\sigma^2) + j\\mathcal{N}(0, \\sigma^2)$.Rician Fading (LOS - Strong Line-of-Sight):Used for satellite or open-field communications where a primary dominant signal exists alongside scatter. It is parameterized by $K$ (the ratio of the dominant path power to the multipath power).$$p(r) = \\frac{r}{\\sigma^2} e^{-\\frac{r^2 + s^2}{2\\sigma^2}} I\_0\\left(\\frac{rs}{\\sigma^2}\\right)$$(where $s$ is the dominant path amplitude, $I\_0$ is the modified Bessel function of the first kind)4.
